# ZERO Intelligence — Known Limitations & Non-Goals
**Milestone:** 8.0.0 — ZERO Intelligence  
**Component:** Boundary Definition & Operational Constraints  

---

## 1. Explicit Architectural Non-Goals

1. **Not a Multi-Billion-Parameter Cloud Replacement:** ZERO Intelligence does not attempt to fit a 70B parameter frontier model onto a 4 GB RAM Intel Celeron J3355 machine. Local inference is strictly reserved for micro-models (15M to 35M parameters) tailored for intent classification, text completion, and safe automation.
2. **Not an Autonomous System Root:** The AI assistant is never permitted to autonomously modify kernel ring 0 memory, bypass capability checks, or alter bootloader parameters.
3. **No Unaudited Background Actions:** The AI cannot silently delete files, open unfirewalled network listening sockets, or terminate critical processes without audit events and explicit user consent.
4. **Not a Web-Scraping Browser Wrapper:** ZERO Intelligence does not depend on Node.js, Electron, Python runtimes, or Chromium engines. All kernel and desktop components are native C and assembly.

---

## 2. Hardware-Imposed Boundaries

- **No Dedicated NPU / TPU:** Acceleration relies exclusively on standard x86_64 SSE4.2 / AVX2 SIMD instructions.
- **Single-Channel Memory Bottleneck:** On Celeron Apollo Lake platforms, memory bandwidth is capped at ~12.8 GB/s. As a result, model weights must remain small enough to fit within L2/L3 CPU caches or low-latency DRAM pages.
- **Single Active Model Restriction:** Because system RAM is shared with the framebuffer, users cannot load multiple multi-hundred-megabyte models simultaneously.

---

## 3. Security Considerations & Boundary Assurances

- **Prompt Injection Defense:** Action proposals generated by the assistant are parsed strictly into typed enum data structures (`ai_action_t`) rather than raw shell strings. Arbitrary shell command concatenation is architecturally impossible.
- **Immutable Sandbox Jail:** Even when an action is user-approved, it executes within the process's existing sandbox jail path, preventing directory traversal escapes (`../`).
- **Audit Tamper-Resistance:** Audit records written to the security log buffer are governed by ring 0 kernel memory protections; an unprivileged user process cannot modify past AI audit entries.
