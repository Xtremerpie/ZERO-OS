# Design System (identity for all milestones)

Direction: cinematic, tactical, minimal, precise, high contrast, lightweight. Serious independent
computing system — no neon, no random gradients, no oversized rounded cards, no generic AI-dashboard look.

## Tokens (as used in 0.0.0 boot banner)

| Token | RGB | Use |
|-------|-----|-----|
| `black` | `#0A0A0A` | background |
| `graphite` | `#1C1C1E` | panels (banner) |
| `gold` | `#C9A227` | muted gold accent, rules, warnings |
| `crimson` | `#B3202B` | accent edge; panic/error text uses `#D0283A` |
| `white` | `#E8E8E8` | controlled white, primary text |
| `grey` | `#8A8A8A` | secondary text, debug |

Planned appearance profiles (5.0.0): ZERO Tactical, Minimal, Crimson, Classic, Developer.
Typography, spacing grid, icon set, window hierarchy and motion rules are defined when the compositor exists (4.0.0).
Rules: keyboard-navigable, readable text, animations optional, UI never depends on a browser.
